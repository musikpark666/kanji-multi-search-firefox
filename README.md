# 漢字一括検索 — Firefox拡張機能

一字の漢字を、複数の辞典や文字データベースでまとめて検索できる個人用Firefox拡張機能です。

## 主な機能

- ポップアップに漢字を一字入力し、選択したサイトをまとめて開く
- Firefox 139以降では、新しいタブを`漢字 願`のようなタブグループにまとめる
- サイトの選択状態と最近検索した漢字8字を保存する
- ウェブページ上で漢字を選択し、右クリックからすぐに検索する
- `Alt+Shift+H`で検索ポップアップを開く
- 外部サーバーへの独自通信や利用者データの収集を行わない

## 標準で開くサイト

- NAVER漢字辞典
- NAVER日本語辞典
- 漢字辞典オンライン
- zi.tools
- ナムウィキ
- 英語版ウィクショナリーの「Glyph origin」節
- 日本語版ウィクショナリーの「字源」節

ポップアップから次のサイトも選択できます。

- 日本語：漢字ペディア、コトバンク、Jisho.org、Weblio辞書
- 筆順：KanjiVG
- 字形・字源：Hanziyuan
- 専門資料：香港中文大学漢字データベース、Unicode UniHan、GlyphWiki
- 中国語・古典：漢典、Chinese Text Project

## Firefoxで試用する

1. アドレスバーに`about:debugging`と入力します。
2. 左側の**このFirefox**を選択します。
3. **一時的なアドオンを読み込む**を押します。
4. このフォルダーの`manifest.json`、または同梱の`.zip`ファイルを選択します。
5. ツールバーのパズルアイコンから**漢字一括検索**をピン留めすると便利です。

一時的にインストールした拡張機能は、Firefoxを再起動すると削除されます。継続して使用するには、Mozilla Add-onsで署名済みパッケージを作成する必要があります。

## 使い方

ツールバーの拡張機能ボタンを押し、`願`のように漢字を一字入力して**まとめて開く**を押します。ウェブページ上の漢字を選択して右クリックし、**選択した漢字を一括検索**を選ぶこともできます。

サイトの選択状態は自動的に保存されます。右クリック検索でも、最後に保存したサイトの選択状態が使用されます。

## 権限

- `menus`：選択した文字を検索する右クリックメニューを表示します。
- `storage`：サイトの選択状態と最近の検索履歴をこの端末に保存します。
- `tabGroups`：開いた検索タブを一つのFirefoxタブグループにまとめます。

ウェブページの内容を読み取ったり変更したりするホスト権限は要求しません。

## カスタマイズ

サイト一覧とURLの規則は`sites.js`にあります。項目を追加するか`defaultEnabled`の値を変更した後、`about:debugging`で**再読み込み**を押すと変更が反映されます。

## 既知の制限

- NAVER辞典は項目URLに内部IDを使用するため、個別項目ではなく検索結果を開きます。
- 漢字辞典オンラインでは、内部番号の項目へ移動するために拡張機能内の中継ページを一時的に経由します。
- サイト側のURL構造が変更された場合は、該当サイトの`buildUrl`規則を修正する必要があります。
- 一部の稀少な漢字は、検索先のサイトで対応していない場合があります。
